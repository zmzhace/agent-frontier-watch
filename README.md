# Agent Frontier Watch

追踪 LLM 与 Agent 最值得关注的四条前沿主线：

1. **RSI / 自动化 AI 研发**：AI 是否正在参与构建下一代 AI？
2. **决策模型 / Jev**：Agent 的路由、判断和验证是否会从生成式 LLM 中独立出来？
3. **可验证搜索**：当答案可以自动评分时，Agent 能否持续搜索出更好的算法和工作流？
4. **Agent Control**：长时间运行、拥有真实权限的 Agent 应该怎样被监控、限制和叫停？

> 最后核验：2026-09-23。这个领域变化很快；本文档优先引用论文、实验室原始发布和可复现实验。

## 一张图看懂四条线

```text
目标与改进方向（RSI / 自动化 AI 研发）
                   │
                   ▼
       低成本选择下一步（Jev / 决策模型）
                   │
                   ▼
  生成候选 → 执行 → 自动评分 → 保留经验（可验证搜索）
                   │
                   ▼
 权限、沙箱、监督、审计、停止机制（Agent Control）
                   │
                   └─────────── 安全地进入下一轮
```

这四条线不是四个互不相关的热点，而是一个自我改进系统所需的四组零件。当前系统已经能形成局部闭环，但尚未实现无需人类确定目标、定义评估和决定部署的完整 RSI。

## 当前判断

| 方向 | 2026 年最新信号 | 成熟度 | 最大缺口 |
|---|---|---:|---|
| RSI / 自动化 AI 研发 | OpenAI 报告“自动化研究实习生”；Anthropic 披露 AI 已深度参与内部 R&D | 早期生产化 | 研究品味、目标选择、独立验证 |
| Jev / 决策模型 | TypeSafe 发布只做结构化决策、不生成文本的 System One Model | 极早期 | 缺少独立、公开、同口径评测 |
| 可验证搜索 | AlphaEvolve 已用于算法和基础设施优化；AlgoEvo、AEvo 推进经验驱动的长程搜索 | 特定领域有效 | 高质量、抗投机的自动评分函数 |
| Agent Control | DeepMind 发布 AI Control Roadmap；CoT 监控、沙箱和分级权限成为系统设计重点 | 快速工程化 | 监督器可靠性、规避监控、跨 Agent 风险 |

## 证据等级

- **A — 原始测量或同行评审结果**：有方法、数据或可复现实验。
- **B — 一手机构披露**：来自实验室或厂商，但主要依赖其内部数据。
- **C — 预印本 / 早期研究**：方法有价值，结论尚需更多复现。
- **D — 推断或市场叙事**：用于提出假设，不作为事实结论。

## 一句话结论

真正值得关注的变化并不是“Agent 会不会完全替代人”，而是：**执行、决策、搜索和控制正在被拆成不同模型与系统层；当这些层能够可靠闭环时，局部自我改进才会逐渐接近完整 RSI。**

## 更新原则

收录内容必须至少满足一项：

- 显著推进 Agent 的自主研究、长期执行或自我改进能力；
- 提出新的 Agent 系统组件或计算范式；
- 提供可复现的自动评估、搜索或控制方法；
- 披露足以改变我们对能力边界或风险判断的新数据。

不收录只有演示视频、没有方法说明的产品宣传。
